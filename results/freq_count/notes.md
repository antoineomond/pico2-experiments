# Comparison baseline experiments clock sources used or not as clock ref 
Setting the XOSC as the reference clock when using the ROSC as the processor clock makes the power usage similar as when using XOSC as both reference clock and processor clock. When using the ROSC as processor clock however, the duration of the experiments is longer. Purely in terms of performances, there is no benefits in keeping the XOSC activated as clock ref. In termes of accuracy however (e.g., to track timing), having the XOSC during the execution of benchmarks allow to have more precision when doing active wait.
